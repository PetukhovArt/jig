A wrong test (it cannot fail when the behavior it names breaks) and a wrong comment (the code contradicts it) are `Important` now, class `false-guarantee` in the default taxonomy; redundant ones stay `Nit`. Angles 16 and 17 have ceiling `Important`, so `quick` and inline re-reviews run them whenever the diff has tests or added comments, and the fix-hunk triage no longer drops them. Angle 17 also reads a doc comment whose code the diff changed.
