C# in the comment and test gates.

- `.cs` files get the comment gate: `//`, `///` and `/* */` comments are found past regular, verbatim, interpolated and raw string literals and char literals; preprocessor directives are not comments, `// <auto-generated>` is a tool directive.
- `#pragma warning disable` and `#nullable disable` are denied every time, like `eslint-disable`.
- A new `[Fact]`, `[Theory]`, `[Test]`, `[TestCase]`, `[TestCaseSource]`, `[TestMethod]` or `[DataTestMethod]` method in a `*Test.cs` or `*Tests.cs` file or under a `*Tests/` folder is a new test case for the test gate; a new `[InlineData]` or `[TestCase]` row on an existing method is not.
