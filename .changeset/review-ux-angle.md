UX gets one criterion, atom `ux`, that every UI step reads: values of any realistic size render readably (the box owner is found first, so a project wrapper or library component that already guards the case is not a defect), every state exists, numbers and time are formatted, every action is reachable, motion is fast and rare, plus a worst-case data catalog. `jig-review` angle 18 applies it to diffs that change UI files on its own finder kind `ux` (role `finder`, standard tier, high effort, `tiers.ux` overrides, selector token `ux`, `angles.18.enabled: false` turns it off); a defect the user cannot read past or reach is `Important`, class `broken`. The `feature`, `bug-bash` and `ui-match` flows name the atom where they build, attack or check UI.
