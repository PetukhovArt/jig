# 16 · Redundant tests

**Class:** cleanup. **Category:** `simplification`. **Gate:** only `CONFIRMED`. **Atom:** `tests`: the criterion.

**Trigger:** every test added or changed in the diff. Untouched tests are not judged.

**Candidate cap:** none; every redundant test is returned ([finders](../steps/04-finders.md#what-a-finder-returns)).

**The question:** is the test redundant by the criterion: it does not fail when the behavior breaks, fails when only internals change, repeats another test, is junk (a trivial assertion, an expected value computed by the code under test, a mock of the unit under test), or is not warranted at all.

**Output:** a thread, although it changes no behavior: a redundant test pollutes the context of later model runs ([shape gate](../gates/shape.md#shape-gate)).

**Evidence:** the test line plus what it asserts and which item of the criterion it fails.

**Thread:** one per file ([merge per file](../steps/06-rank.md#merge-per-file)).
