# 17 · Redundant comments

**Class:** cleanup. **Category:** `simplification`. **Gate:** only `CONFIRMED`. **Atom:** `comments`: the criterion and its allowlist.

**Trigger:** every comment or doc comment added or changed in the diff.

**Candidate cap:** none; every redundant comment is returned ([finders](../steps/04-finders.md#what-a-finder-returns)).

**The question:** the comment fails the criterion: it is not in the allowlist, or the code contradicts it.

**Output:** a thread, although it changes no behavior: a redundant or lying comment pollutes the context of later model runs ([shape gate](../gates/shape.md#shape-gate)).

**Evidence:** the comment line plus the allowlist item it fails, or the code line that contradicts it.

**Thread:** one per file ([merge per file](../steps/06-rank.md#merge-per-file)).
