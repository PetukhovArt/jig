# 2 · Removed behavior

**Class:** bug. **Category:** `correctness`. **Atom:** `change-impact`.

**Trigger:** any removed or replaced line.

**Procedure:**
1. Name in words the rule this line held: a check, an order, a cleanup, a default, a resource release.
2. Find the place in the new code where the rule is restored.
3. Not found: a candidate.

**Evidence:** the removed line plus the claim of where exactly the rule no longer holds.

Naming the rule before the search is required. Without it step 2 turns into "looks fine".
