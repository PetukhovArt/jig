# 3 · Call tracing

**Class:** bug. **Category:** `correctness`. **Atom:** `change-impact`.

**Trigger:** every changed function.

**Procedure.** Search the project for who calls it and whom it calls. Then check:
- the function now requires more than before: a new precondition;
- the shape of the return value changed;
- a new exception appeared;
- a dependency on call order appeared;
- a neighbouring edit in the same diff made an existing call unsafe.

**Evidence:** both sides: the changed contract and the concrete call site that no longer fits it. For a contract between client and server, both sides in view.

Angle 3 walks call edges. A place the call does not reach is the work of [12](12.guard-siblings.md).
