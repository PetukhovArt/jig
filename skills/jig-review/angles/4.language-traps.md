# 4 · Language traps

**Class:** bug. **Category:** `correctness`. **Atoms:** `typescript` for TypeScript, `effects` for reactive code.

A framework-agnostic base set for JavaScript and TypeScript; for another language, its own traps of the same kinds. The project's review document may add framework rules.

**Look for:**
- `==` with type coercion;
- a stale closure over a mutable variable;
- a promise without `await`, a lost reject;
- a race between parallel async flows;
- `any` and `as` hiding a real type mismatch;
- time zones and daylight saving time;
- float equality.

**Evidence:** the quoted line plus the mechanism from the list, named explicitly.
