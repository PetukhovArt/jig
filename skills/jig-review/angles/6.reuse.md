# 6 · Reuse

**Class:** rules. **Category:** `reuse`. **Gate:** only `CONFIRMED` of the rule form ([verify](../steps/05-verify.md)). **Atom:** `one-way`.

**Trigger:** the diff re-implements what the project already has: a helper, hook, util, component.

**Procedure.** Name what the new code does in one phrase, then search the project for an existing implementation by its key symbols and by that phrase (names, signatures, the same literal or regex). Read the candidate before claiming it fits: same inputs, same edge cases.

**Evidence:** the path and symbol of the existing implementation, the new copy's line, plus the invariant the copy holds.

**Not a finding:** a copy without an invariant: a helper, a one-line predicate, the same CSS ([shape gate](../steps/05-verify.md#shape-gate)).
