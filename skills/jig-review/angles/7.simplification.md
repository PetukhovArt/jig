# 7 · Simplification

**Class:** cleanup. **Category:** `simplification`. **Gate:** only `CONFIRMED`. **Atoms:** `do-less`, `reader-cost`, `dead-code`.

**Trigger:** the same behavior is reached with noticeably less code, or with one entity fewer.

**Evidence:** the named entity or branch that disappears, plus the claim that behavior does not change.

**Output:** not a thread. `CONFIRMED` gets `status: "optional"` and goes as an item into the one FYI note ([shape gate](../gates/shape.md#shape-gate)).

**Frequent forms:** an extra layer or delegate with one caller (atom `reader-cost`); a flag, parameter or extension point without a second consumer (atom `do-less`); an export, file or branch nothing reaches (atom `dead-code`).
