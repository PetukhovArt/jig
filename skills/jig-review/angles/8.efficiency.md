# 8 · Efficiency

**Class:** cleanup. **Category:** `efficiency`. **Gate:** only `CONFIRMED`. **Atoms:** `effects`, `why-this-number`.

**Look for:**
- extra work on a hot path;
- a closure keeping a large scope alive: a leak;
- an expensive value recomputed on every call where one computation is enough.

**Evidence:** the call site proving the frequency plus the line doing the work.

**Severity:** `Nit`, like all cleanup, except a leak: a `CONFIRMED` leak with the quoted holding place (a closure, a subscription without unsubscribe, a listener without remove) is `Important`. A long-lived application with a leak has broken behavior, not a style issue.

**Output:** extra work off a proven hot path is a simplification: `status: "optional"`, an item of the FYI note, not a thread ([shape gate](../gates/shape.md#shape-gate)).
