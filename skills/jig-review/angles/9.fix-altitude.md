# 9 · Fix altitude

**Class:** cleanup. **Category:** `altitude`. **Gate:** only `CONFIRMED`. **Atoms:** `root-causes`, `do-less`.

**Trigger:** the edit is made at the wrong depth. Four forms:
- a patch over shared infrastructure where the infrastructure itself should change;
- an infrastructure change where a local fix belongs;
- **a branch in a foreign flow:** the diff inserts a condition or special case of its feature into an existing flow that does not belong to this feature (a mode or flag check in the middle of a shared handler, an `if` for one scenario in someone else's function). An extension point that was bypassed already exists: that is [angle 13](13.architecture.md), not this one;
- **a reshape instead of a patch:** another layout of the same diff removes a whole branch, helper or mode with the same behavior, because the decision moves to where it is already made. When only lines inside the same structure got shorter: that is [angle 7](7.simplification.md).

**Evidence:** the named module that actually owns the decision. By form:
- a branch in a foreign flow: the quoted line of the inserted branch, the flow it tangles (the function and its purpose), and the owner where this feature's decision already lives or should live. The branch makes the foreign flow a second owner of the decision; otherwise it is a convention ([shape gate](../gates/shape.md#shape-gate));
- a reshape: what disappears (a branch, helper, mode) with quoted lines, the new place of the decision, and why behavior stays the same: which inputs went down the disappearing path and where they are handled after the reshape.
