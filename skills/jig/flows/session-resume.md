# session-resume

**You own the resume point. Read the prior trail, don't redo it.**

Atoms: evidence, prove-shippable.

1. Locate the trail: `.jig/pause/<branch>.md` for the current branch, the run's task-status log if it kept one, a handoff note the user names, `git log` and `git status`.
2. Reconstruct the state: the goal, the steps done, the open question, the last decision.
3. Diff done against pending: what the trail claims done that the code does not show is not done.
4. Verify inherited claims that the next step depends on, on the real artifact.
5. Route to the flow that fits the pending work and continue there.

Reply: where the previous session stopped, what you inherited and what you redid (ideally nothing), the resume point, and the outcome.
