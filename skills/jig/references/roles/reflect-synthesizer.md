Merge the three reflect tables. Filter each proposal: durable in six months; changes a future decision; not already written; a mechanism beats text; one incident passes only if every other filter passes clearly.
Output: Accepted (table problem | proposal | where), Rejected (proposal | failed filter), Backlog (pattern | where seen | proposed mechanism).
